# Healthcare-Admissions-Analysis-Using-SQL

**Project Overview**

This project analyzes healthcare admission data to uncover insights related to patient demographics, hospital utilization, operational efficiency, medical conditions, and billing performance.

The analysis was performed using SQL, including data cleaning, duplicate removal, aggregation, filtering, and window functions.

**Business Questions Answered**

How many patients are admitted daily?
Which age groups have the highest admissions?
Which medical conditions are most common?
Which hospitals receive the most admissions?
What is the average patient length of stay?
Which conditions generate the highest billing amounts?
How much billing is associated with each insurance provider?

**SQL Concepts Used**
-Aggregate Functions (COUNT, SUM, AVG)
-Date Functions (DATEDIFF)
-Filtering (WHERE, HAVING)
-Grouping (GROUP BY)
-Window Functions (ROW_NUMBER)
